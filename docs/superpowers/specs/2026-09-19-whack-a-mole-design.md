# 打地鼠儿童游戏 — 设计文档

日期：2026-09-19
状态：已获用户批准

## 目标

面向儿童（低龄，约4-10岁）的阳光草坪主题打地鼠游戏，纯前端 HTML+CSS+JS 实现，无任何外部依赖。30 关由易到难。画面精美、地鼠可爱、环境优美、对眼睛友好。

## 技术架构

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构：开始屏、关卡地图、游戏场、结算屏 |
| `css/style.css` | 全部视觉与动画：场景、地鼠、锤子、特效、护眼主题 |
| `js/levels.js` | 30 关配置表 |
| `js/game.js` | 游戏主逻辑：弹洞、计分、计时、过关判定 |
| `js/audio.js` | Web Audio API 合成音效 + 全局静音 |

## 视觉设计（儿童友好 + 护眼）

- 阳光绿草山坡：柔和浅蓝渐变天空、太阳、白云、远处山丘、草地花朵
- 地鼠用内联 SVG 手绘：圆润 Q 版、大眼睛、粉腮红；露出 / 缩回 / 被打晕三态动画
- 锤子跟随鼠标/触摸，点击锤落；打中爆出星星泡泡粒子
- 关卡过渡屏大字鼓励语，结算屏三颗星评级

### 护眼规范（硬性要求）
- 不启用高饱和荧光色；柔和明亮奶油色/淡黄为底色，不用纯白背景
- 不用纯黑文字，用深棕/深绿
- 禁止快速频闪与突然高亮；动画 200-300ms 平滑过渡
- 大字、宽松间距、圆角、无尖锐边缘
- 关卡时长 30-50 秒，关卡间休息过渡屏
- 「🌙 护眼模式」开关：一键切换柔和月光配色

## 30 关难度曲线

- 洞数：1-10 关 3×3，11-20 关 4×4，21-30 关 4×4 并提速
- 难度维度：地鼠出现间隔缩短、停留时间缩短、目标分提高、限时 30-50 秒
- 每 3 关插入一只金色星星鼠（出现极短、分极高）
- 点空洞不扣分（儿童友好）；超时未达标判失败，可重试

## 交互与数据流

1. 开始屏 → 关卡地图（已通关带星星）→ 点击/顺序开始关卡
2. 关卡 5 秒倒计时内玩家必须达标目标分，超时失败
3. 命中：地鼠晕倒动画 + 加分 + 星星粒子 + 音效
4. 金鼠命中：大加分 + 庆祝音效
5. 完成 30 关全部通关

## 成功标准

- 电脑浏览器直接打开 `index.html` 即可运行（无需服务器）
- 鼠标与触摸（平板）均可玩
- 30 关全部可玩、难度单调递增
- 无外部资源依赖，离线可用
